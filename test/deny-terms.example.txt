# deny 词表示例（**本文件只是形状示范，不含任何真实标识**）
# 用法：node test/redact-scan.mjs --deny-file <这份文件在仓外的副本>
# 为什么要有这一份：规则表只放通用形状（内网段 / 用户目录 / 盘符 / 密钥名形状 / 服务商字样），
#   本部署专有的词（私有对端机名、本机主机名、中转服务器地址、生产树路径……）一律从仓外注入。
#
# 每行：名字<TAB>正则<TAB>说明
# 注意：本文件本身也会被扫描，所以示例里**不要写带盘符的完整路径**（盘符路径是通用规则，
#   写了就会命中，要么白名单要么改掉；示例用目录名代替）。
示例对端机名	example-host-a	某套私有部署的对端机名（占位）
示例本机主机名	example-workstation	某台工作机的主机名（占位）
示例中转地址	203\.0\.113\.\d+	中转服务器的公网地址段（RFC 5737 保留段，占位）
示例私有中转仓	demo-mailbox-agent	私有中转仓的具体路径（占位）
示例中转侧账号	demo-relay@example.invalid	中转侧账号 / 密钥名（占位）
示例生产树（目录名占位）	example-prod-tree	本机生产工具树（占位；真词表里写你自己的盘符路径）

#   每行一个词          → 当作字面词，自动转义 + 词边界
#   整份 JSON 数组      → [{"name":"…","pattern":"…","why":"…"}]
